# Smoke Test

## 1. 테스트 목적

시나리오 C의 전체 요청 흐름이 정상적으로 연결되는지 확인한다.

부하를 주기 전, 로그인 후 토큰 발급부터 게시글 작성, 작성한 게시글 조회, 댓글 작성, 댓글 조회까지 API 호출이 순서대로 성공하는지 검증한다.

## 2. 테스트 대상 시나리오

| 항목 | 내용 |
|---|---|
| 시나리오명 | Scenario C - 로그인 사용자의 글 작성 및 댓글 작성 |
| 테스트 환경 | local |
| 실행 일자 | 2026-05-20 |
| 실행 도구 | JMeter |

## 3. 실행 조건

| 항목 | 값 |
|---|---:|
| Number of Threads | 1 |
| Ramp-up Period | 1초 |
| Loop Count | 1 |
| 총 요청 수 | 6 |

## 4. 실행 API

| 순서 | API | 설명 |
|---:|---|---|
| 1 | POST /auth/token | 로그인 및 accessToken 발급 |
| 2 | GET /boards | 게시판 목록 조회 |
| 3 | POST /boards/2/posts | 게시글 작성 |
| 4 | GET /posts/{postId} | 작성한 게시글 상세 조회 |
| 5 | POST /posts/{postId}/comments | 댓글 작성 |
| 6 | GET /posts/{postId}/comments | 댓글 목록 조회 |

## 5. 실행 결과

| 항목 | 결과 |
|---|---:|
| 총 요청 수 | 6 |
| 성공 요청 수 | 6 |
| 실패 요청 수 | 0 |
| 오류율 | 0.00% |
| 결과 | 성공 |

## 6. 결과 해석

시나리오 C의 전체 흐름은 정상적으로 실행되었다.

로그인 요청에서 발급된 accessToken을 이후 게시글 작성과 댓글 작성 요청의 Authorization 헤더에 사용했고, 게시글 작성 후 생성된 게시글 ID를 상세 조회와 댓글 작성/조회 요청에 연결했다.

따라서 시나리오 C는 부하 테스트를 진행하기 전 기본 요청 흐름 검증을 통과했다.

다만 게시글 작성 API의 응답 시간이 약 3.6초로 다른 API보다 높게 측정되었다. 현재는 표본 수가 1개이므로 병목으로 단정하지 않고, 이후 반복 실행 및 단계별 부하 테스트에서 지속적으로 지연되는지 확인한다.

## 7. 확인된 문제

| 문제 | 원인 | 해결 |
|---|---|---|
| 동일한 게시글 제목 사용 시 409 Conflict 발생 가능 | 게시글 제목 중복 검증 정책으로 인해 같은 title을 반복 요청하면 충돌 발생 | JMeter 함수로 title에 thread number, counter, time 값을 포함하여 요청마다 고유한 제목을 생성 |
| C03 게시글 작성 응답 시간이 상대적으로 높게 측정됨 | 표본 수 1개라 일시적 지연인지 지속 지연인지 판단 불가 | 이후 반복 실행 및 단계별 부하 테스트에서 C03 응답 시간 추이를 확인 |

## 8. 결론

Scenario C 1 / 1 / 1 스모크 테스트 결과, 전체 API 흐름은 오류 없이 정상 동작했다.

따라서 시나리오 C는 부하 테스트 진행 전 기본 연결 검증을 통과했다. 이후 단계에서는 동시 사용자 수를 증가시키며 게시글 작성 API의 응답 시간이 지속적으로 높은지 확인한다.
