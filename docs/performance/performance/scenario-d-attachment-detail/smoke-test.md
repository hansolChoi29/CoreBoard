# Smoke Test

## 1. 테스트 목적

Scenario D 본 부하 테스트 실행 전, 첨부파일이 있는 게시글 조회 흐름이 정상 동작하는지 확인한다.

단일 사용자 기준으로 게시글 목록 조회, 첨부파일 포함 게시글 상세 조회, 댓글 목록 조회 API를 순서대로 호출하여 기능 오류 여부와 응답 시간 기준 초과 여부를 확인한다.

## 2. 테스트 대상 시나리오

| 항목     | 내용                           |
|--------|------------------------------|
| 시나리오명  | Scenario D - 첨부파일이 있는 게시글 조회 |
| 테스트 환경 | local                        |
| 실행 일자  | 2026-05-20                   |
| 실행 도구  | JMeter                       |

## 3. 실행 조건

| 항목                | 값  |
|-------------------|----|
| Number of Threads | 1  |
| Ramp-up Period    | 1초 |

| 순서 | API                                  | 설명                       |

|  2 | GET `/posts/{postId}`                | 첨부파일이 있는 게시글 상세 조회       |
|  3 | GET `/posts/{postId}/comments`       | 게시글 댓글 목록 조회             |
|  4 | 해당 없음                                | 이번 Smoke Test에서는 실행하지 않음 |
|  5 | 해당 없음                                | 이번 Smoke Test에서는 실행하지 않음 |

## 6. 결과 해석

기능 오류는 발생하지 않았고 모든 요청은 정상 응답했다.

하지만 게시글 목록 조회 API가 3,075ms로 측정되면서, 전체 p95 응답 시간도 3,075ms로 나타났다.

반면 첨부파일 포함 게시글 상세 조회는 55ms, 게시글 댓글 목록 조회는 9ms로 측정되었다.  
따라서 이번 Smoke Test에서 확인된 지연 구간은 첨부파일 상세 조회가 아니라 게시글 목록 조회 API다.

사전에 정의한 기준인 p95 3초 초과에 해당하므로, 본 부하 테스트를 진행하지 않고 게시글 목록 조회 API의 병목 원인을 먼저 확인한다.

## 7. 확인된 문제

| 문제                                    | 원인                                                                     | 해결                                                                     |
|---------------------------------------|------------------------------------------------------------------------|------------------------------------------------------------------------|
| Smoke Test 단계에서 p95 응답 시간이 3초를 초과함    | 게시글 목록 조회 API가 3,075ms로 측정됨                                            | 게시글 목록 조회 쿼리, 정렬, count query, 인덱스 사용 여부를 먼저 확인한다                      |
| 예상 병목과 실제 병목이 다름                      | 첨부파일 상세 조회가 느릴 것으로 예상했으나 실제 지연은 게시글 목록 조회에서 발생함                        | 병목 가정을 유지하지 않고 실제 측정 결과 기준으로 분석 대상을 변경한다                               |
| Grafana HTTP 요청량 패널에 데이터가 충분히 표시되지 않음 | Smoke Test 요청 수가 3개뿐이고 실행 시간이 짧아 Prometheus 수집 주기에 충분히 잡히지 않았을 가능성이 있음 | Smoke Test 판단은 JMeter 결과를 기준으로 하고, Grafana는 부하 지속 시간이 있는 테스트에서 함께 확인한다 |

## 8. 결론

Scenario D Smoke Test 결과, 오류율은 0.00%로 기능상 문제는 없었다.

하지만 게시글 목록 조회 API가 3,075ms로 측정되면서 사전에 정의한 중단 기준인 p95 3초를 초과했다.

따라서 Scenario D 본 부하 테스트는 중단하고, 먼저 게시글 목록 조회 API의 병목 원인을 분석한다.
