# Load Test

## 1. 테스트 목적

Scenario D의 첨부파일 게시글 조회 흐름을 대상으로 응답 시간과 자원 사용률을 확인한다.

이전 Smoke Test에서는 게시글 목록 조회 API가 p95 3초 기준을 초과했다.

이후 게시판별 게시글 목록 조회를 `Page`에서 `Slice`로 변경했고, 복합 인덱스를 적용했다.

이번 테스트에서는 개선 이후에도 부하 증가 상황에서 안정적으로 동작하는지 확인한다.

## 10. 결론

Scenario D 부하 테스트는 통과로 판단한다.

5 users, 10 users, 20 users, 30 users 단계 모두 오류율은 0.00%였다.

최종 30 users 기준 전체 평균 응답 시간은 2ms, p95는 5ms, 최대 응답 시간은 10ms였다.

모든 API가 p95 10ms 이하를 유지했다.

서버 자원 사용률에서도 병목 징후는 확인되지 않았다.

특히 게시글 목록 조회 API는 개선 전 Smoke Test에서 3,075ms까지 지연되었으나, 30 users 단계에서는 p95 5ms로 안정적으로 응답했다.

따라서 `Page`에서 `Slice`로 변경하고 복합 인덱스를 적용한 개선 효과가 부하 증가 상황에서도 유지되었다고 판단한다.
