# Smoke Test

## 1. 테스트 목적

본격적인 부하 테스트를 수행하기 전에, JMeter 시나리오가 CoreBoard API를 올바른 경로와 파라미터로 호출하는지 확인한다.

이 테스트는 성능을 판단하기 위한 테스트가 아니라, 시나리오 B의 API 호출 흐름이 정상적으로 동작하는지 검증하기 위한 사전 점검이다.

검색 조건이 들어갔을 때 게시글 목록 조회 성능이 어떻게 달라지는지 확인한다

검색은 일반 목록 조회보다 조건 필터링 비용이 커질 수 있으므로 응답 시간 변화를 비교한다

## 2. 테스트 대상 시나리오

| 항목     | 내용                      |
|--------|-------------------------|
| 시나리오명  | Scenario B - 검색 사용자의 흐름 |
| 테스트 환경 | local                   |
| 실행 일자  | http://localhost:8080   |
| 실행 도구  | JMeter                  |

## 3. 실행 조건

| 항목                | 값  |
|-------------------|----|
| Number of Threads | 1  |
| Ramp-up Period    | 1초 |
| Loop Count        | 1  |
| 총 요청 수            | 2  |

## 4. 실행 API

| 순서 | API                                                                    | 설명          |
|---:|------------------------------------------------------------------------|-------------|
|  1 | GET /boards/{boardId}/posts?keyword=test&page=0&size=10&direction=DESC | 게시판별 게시글 검색 |
|  2 | GET /posts/{id}                                                        | 게시글 상세 조회   |

## 5. 실행 결과

| API                                                                    | 표본 수 | 평균 응답 시간 |   최소 |   최대 |  오류율 |
|------------------------------------------------------------------------|-----:|---------:|-----:|-----:|-----:|
| GET /boards/{boardId}/posts?keyword=test&page=0&size=10&direction=DESC |    1 |      9ms |  9ms |  9ms | 0.0% |
| GET /posts/{id}                                                        |    1 |     10ms | 10ms | 10ms | 0.0% |
| 총계                                                                     |    2 |      9ms |  9ms | 10ms | 0.0% |

## 6. 결과 해석

Scenario B의 Smoke Test 결과, 총 2개의 API 요청이 모두 정상 응답했다.

검색 조건이 포함된 게시글 목록 조회 API와 검색 결과 게시글 상세 조회 API를 순서대로 호출했고, 전체 오류율은 0.0%였다.

검색 API는 `keyword=test`, `page=0`, `size=10`, `direction=DESC` 파라미터를 포함하여 정상 호출되었고, 이후 검색 결과에 포함된 게시글의 상세 조회 API도 정상
응답했다.

다만 이 테스트는 사용자 1명, Loop 1회 조건에서 수행한 사전 검증이므로 성능 판단 근거로 사용하지 않는다.

이번 결과는 JMeter 요청 경로, HTTP Method, Query Parameter, 검색어, 고정 테스트 데이터가 올바르게 설정되었음을 확인한 결과다.

## 8. 결론

Scenario B - 검색 사용자의 흐름 Smoke Test를 통과했다.

이번 테스트를 통해 JMeter가 검색 조건이 포함된 게시글 목록 조회와 검색 결과 게시글 상세 조회 API를 올바른 순서로 호출할 수 있음을 확인했다.

따라서 다음 단계에서는 동일한 시나리오를 기준으로 동시 사용자 수를 5명, 10명, 20명, 30명으로 증가시키며 Load Test를 수행한다.
